# ReviewMind AI 😎

### AI-Powered Product Review Screenshot Analyzer

---

## 🚀 Overview

ReviewMind AI is a real-world AI web application that analyzes product review screenshots using **OCR (Optical Character Recognition)** and **Transformer-based Deep Learning models**.

Instead of manually reading hundreds of online reviews, users can simply upload multiple review screenshots, and the AI system automatically:

✅ Extracts review text from images
✅ Understands customer opinions
✅ Detects positive & negative insights
✅ Calculates product rating
✅ Generates final buying recommendation

This project combines:

* Computer Vision
* Natural Language Processing (NLP)
* Deep Learning
* Web Development

into one intelligent AI system.

---

# 🔥 Key Features

## 📸 Multi Screenshot Upload

Users can upload multiple review screenshots simultaneously.

---

## 🔍 OCR Text Extraction

Uses EasyOCR to extract review text from uploaded screenshots.

---

## 🧠 Transformer-Based Sentiment Analysis

Uses Hugging Face Transformer models for intelligent sentiment prediction.

---

## 😊 Positive Review Insights

Automatically detects highly positive customer feedback.

Example:

* “Sound quality is amazing”
* “Battery backup is very good”

---

## 😭 Negative Review Insights

Detects customer complaints and negative experiences.

Example:

* “Call quality disappointed me”
* “Build quality is not premium”

---

## ⭐ AI Product Rating System

Generates AI-based product ratings automatically.

Example:

```text
4.7 / 5 ⭐
```

---

## ✅ Final Buying Recommendation

Provides a final purchase recommendation.

Example:

```text
Worth Buying ✅
```

or

```text
Not Recommended ❌
```
